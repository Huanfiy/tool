# 工作室显示器：正对镜头、自发光与整图预览

验证日期：2026-09-06。环境：Chrome `152.0.7977.64`、Three.js `0.170.0`、Puppeteer、ANGLE / SwiftShader。

**本地浏览器回归通过；未部署。移动视口模拟与软件渲染不代表真实手机、GPU 性能或最终美术签收。**

## 修复边界

- **靠近视角**：原目的位置虽接近水平，但 OrbitControls 的 `maxPolarAngle=1.48` 每帧会将其夹回约 5.2° 的俯视。靠近位置现在由屏幕实际中心和世界法线派生；仅屏幕视角允许达到 `π/2`，其他视角恢复原限制。脚本镜头移动前清除环视惯性，避免残余输入改变目的位置。
- **背景覆盖**：保留从全部实际目标及最大环视距离计算的球形覆盖界限，resize 时包含新的屏幕中心。它不依赖原俯视角上限，因此水平视角仍在原半径 / far 的覆盖内。新增契约检查相机位于天空内部且远裁剪面覆盖整个背景。
- **屏幕视觉**：移除覆盖桌面底色的偏灰暖绿规则，使用更清晰的深色、青绿渐变和克制的内部发光边缘。屏幕实体边框使用独立材质，原桌面点光改为屏幕附近的稳定冷色补光；不增加灯光数量、阴影、纹理、RAF 或后处理通道。靠近时隐藏全屏纸纹罩层和会遮住横屏图片说明的手势提示；照片本身不加泛白反光或亮度滤镜。
- **完整看图**：预览覆盖相册应用区域，不再被夹在两条头部栏之下。返回与计数、可收缩的图像区域、说明分开排布；图片使用明确宽高的 `minmax(0, 1fr)` 网格单元与 `object-fit: contain`，不依赖图片固有尺寸撑开布局。移除会裁掉照片角部的圆角及相框。长说明单行省略，完整内容保留在图片替代文本和说明 tooltip 中。隐藏的相册网格、分类按钮在预览期间保持 inert。
- **交互边界不变**：同一 CSS3D 桌面、深度孔洞和原生输入；靠近 / 退后不重建应用。列表仍可滚动，只有整图预览不滚动。终端仍为浏览器模拟，Robot 仍为静态研究占位，无后端或 API。

## 复跑

```sh
node --test tests/studio-guest.test.js

# 使用环境中已有的 puppeteer-core；不向项目安装依赖。
PUPPETEER_MODULE=/path/to/puppeteer-core \
STUDIO_TEST_OUTPUT=/tmp/studio-monitor-review/after \
node tests/studio-apps-browser.cjs
```

浏览器套件自动启停临时 Python 标准库静态服务器，默认 Chrome 路径为 `/usr/bin/google-chrome`（可用 `CHROME_BINARY` 覆盖）。它也运行 `tests/studio-outdoor.html`。
