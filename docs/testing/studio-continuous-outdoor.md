# 工作室连续户外空间：实现与验证记录

验证日期：2026-09-05（UTC）。实施基线：`718e4d4`。

**状态：生产实现与浏览器契约 / 空间 / 交互回归已落地；真实桌面 GPU、真实手机的时间性能及最终美术签收仍待验收。** 本文不把移动视口模拟或 SwiftShader 微基准记作真机通过。

## 1. 实现边界

- `studio-room.js` 统一提供实际墙体 / 地板 / 窗扇布局、日夜色板和时钟。窗户、景观是 scene 下的同级根节点。
- `studio-window.js` 只负责框、玻璃、把手、热区和机械开合。`update()` 仅在本帧实际姿态改变时返回 `true`；零 dt 不误报，减少动态时即时切换只报告一次。
- `studio-landscape.js` 提供同层墙脚石边、前后转角、细分庭院与低细分远地表。它们是一块连续拓扑，不在精细庭院范围处结束。地表在世界空间宽幅混入纸面色，混色发生在生产 tone mapping / 输出转换之后，不是窗洞或相机位置裁剪。
- 闭合球壳固定在世界空间，使用内向、不透明、正常深度测试的 Basic 材质；不参与雾、阴影和拾取。`studio-landscape-art.js` 按世界经纬绘制低丘、果园、小屋与日月，接缝、极点和下半球回到纸面色。旧窗洞 shader、有限弧面及按窗高计算的 UV 已移除。
- 草木、花朵、石径与云鸟共享几何并实例化；户外不投射动态阴影，地面 / 石边接收阴影，树脚使用低成本接触色。动画使用保守包围球，不逐帧遍历所有实例重算；回归测试检查实例未越出包围体。
- 风力从实际窗扇进度获得，再平滑积分相位；关闭窗户不会缩放绝对坐标而使云鸟跳变。减少动态时户外更新完全冻结；没有新增 RAF。
- 静态纹理仅在主题或桌面 / 移动质量档位改变时绘制。质量切换替换并释放旧纹理，相同主题 / 档位不重复分配。没有动态图集、外部图片、模型或运行时图片服务。
- 书脊颜色输入已改为缓存材质。缓存、合批脱离 scene 的资源、子模块和渲染器采用统一去重释放；Sprite 使用 room 自有几何副本，不释放引擎共享的默认几何。事件、observer 和失败初始化都纳入清理。
- 保留显示器 CSS3D 透明孔洞。实体户外能阻挡设备拾取，也能阻挡 HTML 屏幕的 pointerdown、后续 click 和 wheel；键盘激活按控件中心检查遮挡。

### 覆盖界限不是离散截图结论

对全部实际目标 `T`、背景中心 `C` 和当前最大距离 `Dmax`：

```text
cameraBound = Dmax + max(length(T - C))
radius = max(首轮半径, ceil(cameraBound + 6))
far = max(首轮 far, ceil(radius + cameraBound + 8))
```

当前桌面保守界限约 `36.07`，移动约 `68.46`，实际仍采用半径 `80` / far `160`，near 保留 `0.1`。采样中最大背景相机空间深度约 `144.20`。resize 会从实际 `destination()` 目标重新计算，而不是只依赖预设原始数组。

对最小方位角 `-0.85`，相机还满足 `x + tan(0.85) * z >= min(T.x + tan(0.85) * T.z)`。高树、云鸟及其运动外包围体位于该半平面外侧，低矮草花位于最小相机高度下方；相机目标和位置的凸插值保留这些保守限制。这个检查保护新增资产，不声称修复所有既有室内镜头问题。

原全局 `Fog(30,65)` 保持不变；移动端最远距离下室内变淡属于原雾化表现，不能把这类截图当成原生手机 GPU 性能或新的空间裁剪证明。

## 4. 原生交互与失败回归

已执行：

- 窗扇 / 热区拾取与页头按钮开关窗，状态标签和 `Studio.state.breeze` 一致。
- 在原本命中打印机的射线上加入同级不透明测试物体：命中变为 `null`；禁用它的 raycast 后才重新命中打印机，景观不误触开窗。
- 在物理屏幕前加入不透明测试物体：被遮挡的 Robot 图标不打开应用；移除物体后原生点击正常。额外修复了仅取消 pointerdown 仍会产生 click 的旧问题。
- overview 不靠近即可直接输入并选择 Robot 文本；原生键盘激活、靠近 / 退出，以及七种尺寸间 resize 后草稿保留。访客终端执行 `studio motor` 驱动设备，靠近 / 退出保留终端模式；相册图片查看状态同样保留。
- 屏幕外真实鼠标拖动改变镜头；移动触控滑动使设置面板滚动 153px，但物理显示器位置和宽度不变。
- 使用电脑期间打印进度继续推进；烧录完成、电路板展开、示波器切换、焊台 / 排烟联动、电机、机械臂、浇水至 72% 与八站导览正常。
- 新建标签页并切到前台后，原页确实进入 hidden；观察期间渲染帧和场景时间增量均为 0；恢复前台继续渲染。
- 对正常生产页面启用外部图片请求阻断策略后，3D 场景完整加载，实际外部图片请求为 0；引擎与字体仍按原有 CDN 加载。
- 冷启动阻断实际 Three.js CDN（不是仅阻断本地 room 模块）时显示错误提示，仍可打开 HTML 桌面并输入 Robot 草稿。没有宣称 3D 场景完全离线可用。

终端 / 相册 / Robot 的内部流程未修改。本轮保留原有应用回归，不涉及真实终端桥接、用户密钥或外部模型服务的在线验收。
