# 工作室真机性能验收与美术签收

- 状态：待处理
- 涉及页面：`studio.html`
- 相关约束：[工作室要素约束](../design/workbench.md)

## 背景

工作室的连续户外空间、显示器正对与整图预览、首帧闪屏修复、草丛形态与院子带等改动，均只在 Chrome + SwiftShader 软件渲染与移动视口模拟下完成浏览器契约测试和视觉抽查。这些结果验证了模块契约与资源预算（断言见 `tests/studio-outdoor.html`），但不能代表真实桌面 GPU、真实手机的时间性能或最终美术效果。逐轮的浏览器验证记录已移出工作区，git 历史 `f843e8a`、`e32caaf` 可查。

## 现状

- 契约测试：`tests/studio-outdoor.html`、`tests/studio-apps-browser.cjs` 可复跑，覆盖生命周期、资源预算、像素契约与屏幕对齐。
- 尚无任何真实设备的帧间隔、主线程耗时或纹理上传数据。
- 纸面留白、庭院密度、远景画风、屏幕自发光强度未经用户在真实屏幕上最终确认。

## 建议动作

- [ ] 在同一真实桌面与真实手机上运行当前版本，记录型号、系统、浏览器、GPU、实际 DPR 与热身时间。
- [ ] 安静、环视、窗扇开合、多设备运行、靠近屏幕使用相册各采集至少 30 秒，记录已渲染帧间隔 P50 / P95、主线程更新 / 重绘耗时与纹理上传次数。
- [ ] 判定标准：静置接近 30 fps、活动接近 60 fps；相对上一已验收版本 P95 不恶化超过 10%；若基线本身不流畅，明确列为阻断项而非通过。
- [ ] 真实触屏上检查显示器文字清晰度、补光强度与触控手感。
- [ ] 用户在真实屏幕上确认纸面留白、庭院密度、远景画风；浏览器截图抽查不算美术签收。
- [ ] 通过后将设备与实测数据落档到 `docs/testing/`，并删除本文件。

## 缓办原因

缺少可用的真实设备测试时段；软件渲染下的微基准受计时精度和宿主环境影响，不能替代上述验收。
